# 方向库与停滞退出

此表是待验证假设，不是性能承诺。只迁移适合单线程 CPU 和 AV1 的部分；论文采用的硬件、视频编码器和数据条件不能直接迁移为本 benchmark 的结果。

## 一手参考与迁移假设（2026-11-16 核查）
- GSCV++，arXiv:2611.05359v2，https://arxiv.org/html/2611.05359v2 。原文的方法包括 GOP 共享的能量自适应 SH PCA、Morton 初始化后的局部跨帧排列、坐标高低位非均匀拆分。迁移假设：用单线程实现评估表示与对应关系，后端只用 AV1；不沿用其裁点、其他编码器或并行实现。原文 P-frame 指映射的非锚帧，不必等于视频编码器实际帧类型。
- GSCV，arXiv:2610.07795，https://arxiv.org/abs/2610.07795 。研究无可靠追踪时的锚帧关联映射。迁移假设：局部受限匹配能否补偿独立 Morton 排序破坏的时间一致性；匹配成本必须纳入编码。
- KISS-GS 作者项目，https://fraunhoferhhi.github.io/KISS-GS/ 。研究可模块化属性表示与排序码本。这里只参考可独立消融的表示思路；不采用裁点/训练/GPU 微调，不能把整套系统收益归给编码器。
- 非码本扩展：SH 低秩、可逆预测和分 band 量化作为独立假设；尚未实施或取得收益，不能仅凭文献列名宣称覆盖。

## 本地四篇论文的研究入口
PDF 逐页阅读与页面图像待基线结束后建立；以下在线一手入口用于确认书目信息，不能代替本地具体实现阅读。
- TETRIS-4DGS，https://arxiv.org/html/2610.14663v1 。候选启发：运动/重要性分组与精度分配。其原生 4D 参数、重要性估计和裁剪条件与本项目的逐帧 PLY 不同；不移植裁点/训练。先研究保持点数的 CPU 分组量化消融，非直接复现整套方法。
- SmoothMotionVectors，作者机构页 https://vlg-test.inf.ethz.ch/publications/SmoothMotionVectors-Optimizing-Your.html 。候选启发：GOP 成本与时空运动信号平滑度。原训练约束不适用于冻结输入；迁移假设为不改变已量化轨迹的线性预测/残差表示，需实测，而不是重新训练场景。
- TSOG，https://arxiv.org/html/2607.28049v1 ，作者实现 https://github.com/xiaomi-research/tsog 。候选启发：静态属性与动态参数分开存储，独立时间轴。当前实验锚点是已有 OpsiClear Python codec，并非此作者实现；不偷偷替换锚点。未来若研究官方实现，作为另一个明确命名的锚点记录。
- GSCV++ 对应 paper/GSCV++.pdf，已列上方；本地阅读重点：共享 SH 基、非锚帧映射与 AV1 可用的布局思路。论文中的其他视频编码器设置不在本项目搜索范围内。

## 退出与重入
连续两个无收益变体或同家族三轮后，记录瓶颈并换家族。重试须有新证据（不同重复率、对应关系验证、残差统计、侧信息成本变化），不能仅改随机种子或小幅调参。优先实验预期收益大且可单变量验证的方向；每六轮检查家族覆盖，至少一个非码本实验。
